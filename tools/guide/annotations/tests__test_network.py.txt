== def test_gradient_check(
For every single weight: nudge it by plus and minus 1e-6, measure the loss, and compare `(L+ - L-) / 2h` with what `backward` says. The biases are set to non-zero values first so their gradients are really tested. The relative error must be below 1e-6; it comes out around 1e-9.

== def test_adam_fits_a_tiny_regression(
An end-to-end check that forward, loss, backward and Adam together can drive the loss down: memorise 16 random targets.

== def test_adam_first_step_is_lr_sized(
With bias correction, Adam's first step is the learning rate times the sign of the gradient, whether the gradient is 0.5, -100 or 0.001.
