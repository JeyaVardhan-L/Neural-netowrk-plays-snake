What I wanted

I wanted one project where I understood every number. Most tutorials hand the hard part to a library: you call model.fit() or loss.backward() and something happens. That is fine for work, but it meant I could not answer the questions that come up in interviews. Why does ReLU help? What is the gradient of the loss with respect to the first weight matrix? Why does DQN need a second network?

So the rules were simple. NumPy only for anything that learns. I write the forward pass, the loss, backpropagation and the optimiser myself. Matplotlib and Pillow are allowed for pictures, and pytest for tests, because none of them touch the learning.

Why Snake

Snake is small enough to train on a laptop in seconds, but it is not trivial: the agent has to trade off getting to the food against not trapping itself. There is no dataset of "correct moves". The agent has to discover what works by playing, which makes it reinforcement learning: learning from rewards instead of labels.

That also makes it a good test of understanding. In supervised learning the target is given. Here I had to build the target myself, from the reward and the network's own guess about the future. Chapter 8 is about exactly that.

The plan in one picture

Everything in this project is one loop. The game produces a state, the network turns the state into three scores, the agent picks a move, and the game moves on. In the background, every step is written to a memory, and the network learns from random handfuls of old steps. Click each box to see which file does it.

Day one: the laptop had no pip

I booted into Ubuntu for this, because training is CPU work and Linux makes it easy to use every core. The machine is a laptop with a 13th-gen Intel i5-13420H (12 threads) and 14 GB of RAM. No GPU, and no need for one: the network has 963 parameters.

The first command failed. Ubuntu's Python 3.14 ships without pip and without ensurepip, so python3 -m venv .venv refused to create an environment. The fix without touching the system Python was to create the environment without pip and install pip into it:

terminalsetting up
$ python3 -m venv .venv
The virtual environment was not created successfully because ensurepip is not available.

$ python3 -m venv --without-pip .venv
$ curl -sSL https://bootstrap.pypa.io/get-pip.py -o get-pip.py
$ .venv/bin/python get-pip.py
$ .venv/bin/pip install -r requirements.txt
$ .venv/bin/python -c "import numpy; print(numpy.__version__)"
2.5.5

On a normal Ubuntu install the cleaner fix is sudo apt install python3-venv python3-pip. Either way, a virtual environment is a private folder of packages for one project, so this project's NumPy version can never break another project.

The layout I settled on

snake_ai/         the library
  game.py         Snake: board, rules, the 11 inputs
  network.py      the network: forward, backward, loss, Adam
  agent.py        DQN: epsilon-greedy, replay memory, target network
  training.py     the training loop and evaluation
  baselines.py    random and hand-written policies to compare against
train.py          train a model            -> runs/main/, models/
evaluate.py       measure a model
play.py           watch it play (terminal) or save a GIF
experiments.py    the ablation study       -> results/experiments/
analyze.py        baselines + the 256 possible inputs -> results/analysis.json
make_charts.py    the PNG charts for the README
tests/            42 tests, including a gradient check
docs/             this guide (GitHub Pages)

Two habits from the start. First, the library has no printing and no file paths in it; scripts at the top level do that. Second, everything is seeded. The same seed gives the same game, the same network and the same training run, down to the last digit. I checked this by training twice and getting 26.43 both times. Without that, every comparison in chapter 12 would be guesswork.

IN:Walk me through this project in a minute.
OUT:

It is a Deep Q-Network that learns Snake, written from scratch in NumPy. The game gives the agent 11 binary features: danger straight, right and left, its heading, and which way the food is. A two-layer network, 11 to 64 to 3, outputs a Q-value for each relative move. I train it with Q-learning: rewards of +10 for food and −10 for a crash, a replay memory, a target network and Adam, all hand-written, with a numerical gradient check to prove the backprop is right.

After 400 games, about 12 seconds on a CPU, it averages 26 apples. Then I ran an ablation study over 5 seeds and found the ceiling comes from the 11 inputs, not the learner: the network ends up matching a hand-written rule on 94% of its moves.
