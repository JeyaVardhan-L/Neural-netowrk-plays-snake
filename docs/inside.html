Chapter 13

Looking inside: it learned the rule

I wrote down the obvious strategy as five lines of Python and compared. The network had rediscovered it, and agrees with it on 94% of the moves it plays.

Entry 13 · snake_ai/baselines.py · analyze.py · results/analysis.json

A score needs something to stand next to

Is 26 apples good? On its own the number means nothing. I needed baselines, measured on exactly the same boards. evaluate() accepts any function from state to action, so the network and the baselines run through the same code.

The floor is random moves. The interesting one is a hand-written rule that uses the same 11 inputs the network gets: never step into danger, and among the safe moves prefer one that heads towards the food.

snake_ai/baselines.pyrule_policy
def rule_policy(state):
    d = heading(state)
    safe = [a for a in (STRAIGHT, TURN_RIGHT, TURN_LEFT) if state[_DANGER_INPUT[a]] == 0]
    towards = [a for a in safe if state[_TOWARDS_FOOD_INPUT[turn(d, a)]] > 0]
    if towards:
        return towards[0]
    if safe:
        return safe[0]
    return STRAIGHT

Random play eats 0.16 apples on average and mostly runs into a wall. The rule averages 27.45. The trained network averages 26.43. In other words, from three reward numbers and a few hundred games, the network found a policy as good as the strategy a person would write down after a minute's thought. Not better, not worse.

The whole policy fits in a table

Chapter 3 worked out that the inputs can only form 256 combinations. That means I do not have to guess what the network learned: I can run all 256 through it and look. analyze.py does this, and also counts how often the trained snake actually meets each input during 100 greedy games (39,238 steps).

  • The snake meets 216 of the 256 inputs. The other 40 never happen in its play.
  • The network and the rule pick the same move on 196 of the 256 inputs.
  • Weighted by how often each input comes up, they agree on 93.6% of the moves actually played.

Where they disagree

I went through all 60 disagreements with a few lines of Python. None of them is the network making an obvious mistake:

  • 12 inputs the snake never meets. There was never a training signal for them, so the network's answer is whatever its weights happen to give.
  • 15 trapped positions, where all three danger inputs are on. Every move crashes, so the choice is meaningless. They come up 85 times in 39,238 steps: the last step of a game.
  • 33 positions it really plays, covering 2,416 steps. These are the interesting ones.

In 23 of those 33 there is danger on exactly one side, and in all 23 the network turns away from the danger, where the rule goes straight or turns towards the food. Moving away from your own body keeps open space in front of you. Nobody told it that; it came out of games that ended badly. In 6 positions (181 steps) it even passes up a safe move towards the food to do it. Nine more are plain ties, two moves the rule's own criteria rate as equal, broken by list order on one side and by small Q-value differences on the other, and the last one is a simple difference of preference.

This habit did not make the network beat the rule (26.4 against 27.5, within the noise of one evaluation), so it helps little, if at all. But it is a real learned behaviour, and it is the kind of thing you only find by looking.

The Q-values are readable too. Across the inputs the snake meets, a move into danger averages Q = −10.03, because the target for a crash is exactly −10 with no future. Safe moves average +4.3: some mix of "food soon" and "a crash, eventually".

Why this is the most important result

It explains the ceiling. The network is not failing to learn: it has learned essentially the best simple policy that its 11 inputs allow. More training, a bigger network, a better optimiser: chapter 12 tried all of those and they all land on the same plateau, because the same rule is the answer for all of them. To do better, the snake needs to see more.

IN:How do you know the agent learned something meaningful?
OUT:

Three ways. First, baselines on the same boards: random scores 0.16, the network 26.4. Second, a hand-written rule using the same inputs, avoid danger and head for the food, scores 27.5, so the network matches a sensible strategy it was never told. Third, because there are only 256 possible inputs, I enumerated all of them: the network agrees with the rule on 94% of the moves it actually plays, and the disagreements are mostly ties or inputs it never encounters. So I can say concretely what it learned, and that its limit comes from the inputs.
