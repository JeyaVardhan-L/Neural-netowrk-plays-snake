Chapter 08

Rewards and Q-learning

There is no dataset of correct moves. The target the network learns from is built from the reward it just got plus its own guess about what comes next.

Entry 08 · snake_ai/agent.py: Agent.learn

The vocabulary

Reinforcement learning has its own words, and interviews use them:

  • The agent makes decisions; the environment (the game) responds.
  • At each step the agent sees a state s, takes an action a, gets a reward r and lands in a new state s′. That four-tuple, plus "did the game end", is a transition.
  • One game from start to finish is an episode.
  • A policy is the rule for choosing actions: state in, action out.

What a move is worth

A move should not be judged by its immediate reward alone. Turning towards the food gets 0 now, but leads to +10 a few steps later. So we judge a move by the return, the sum of all future rewards, each one discounted by a factor γ (gamma) per step of delay:

G = r0 + γ r1 + γ2 r2 + γ3 r3 + …

With γ = 0.9, an apple 10 steps away is worth 10 × 0.910 ≈ 3.5 now. Discounting keeps the sum finite, prefers sooner rewards to later ones, and sets a rough horizon: 1 / (1 − γ) = 10 steps for 0.9.

The Q-function Q(s, a) is the expected return if you take action a in state s and play well afterwards. If you knew it, playing would be trivial: in every state, take the action with the biggest Q. Our network's three outputs are its estimate of exactly this, one per move.

The Bellman equation

The return has a recursive structure: the return from now is the reward now, plus γ times the return from the next state. If we play well from the next state, that return is the best Q-value there. So the true Q-function must satisfy:

Q(s, a) = r + γ · maxa′ Q(s′, a′)

This is the Bellman equation, and it gives us a training target without anyone telling us the right answer. For any remembered transition, the right-hand side uses one real reward plus the network's own estimate one step later. Make the left side closer to the right side, over and over, and the real rewards gradually spread backwards through the estimates. This idea, learning a guess from a slightly better guess, is called bootstrapping.

It is easiest to see in a world of five cells.

From the equation to a gradient step

In the corridor, each cell's value is a number in a table. In Snake the "table" is the network, so instead of overwriting a cell, we take a gradient step that moves Q(s, a) towards the target y. The loss is the squared error from chapter 6:

y = r + γ · maxa′ Qtarget(s′, a′) · (1 − terminal)      L = (Q(s, a) − y)2

The (1 − terminal) handles the end of a game. After a crash there is no next state worth anything, so the target is just the reward, −10. This is why chapter 2 kept crashes and time-outs apart: a time-out is not terminal, so its target still includes the future. (Qtarget is a frozen copy of the network, explained in chapter 10.)

snake_ai/agent.pyAgent.learn
s, a, r, s2, terminal = self.memory.sample(cfg.batch_size)

q_next = self.target.predict(s2).max(axis=1)
y = r + cfg.gamma * q_next * (1.0 - terminal)

q, cache = self.net.forward(s)
loss, dq = q_loss(q, a, y)
grads = self.net.backward(cache, dq)
self.opt.step(self.net.params, grads)

Two tests check this exact behaviour. test_target_uses_bellman_equation stores one transition with reward 10 and checks that after 300 updates Q(s, a) is close to 10 + γ max Q(s′). test_terminal_ignores_the_future stores a crash and checks that Q settles at −10, whatever the next state looks like.

Off-policy

Notice the max. The target assumes we play the best move from s′, even if the move actually played next was random. That makes Q-learning off-policy: it learns the value of the greedy policy while following an exploring one. It is also what lets us learn from old transitions in memory, played by an older, worse version of the agent.

What gamma did to the snake

I trained 5 seeds each with four values of γ. Mean score over 100 greedy games:

γscorewhat it means
05.8 ± 7.1only the next reward counts: avoid crashing, eat food that is adjacent
0.530.9 ± 1.9horizon of about 2 steps, the best score
0.9 (default)27.0 ± 3.1horizon of about 10 steps
0.9926.6 ± 1.4horizon of about 100 steps

The surprise is that 0.5 beat 0.9. My explanation: the inputs already point at the food, so the agent does not need a long plan to reach it, and it cannot see far enough to plan around its own body anyway. A long horizon only adds noise to the targets. With γ = 0 the agent is blind to anything more than one step away, like cell 1 in the corridor, and its training score stalls at 11. I kept 0.9 as the default because it is the standard choice and I chose it before running the study; changing it afterwards to the best result would be tuning on the test.

IN:What is the Bellman equation, and how does DQN use it?
OUT:

It says the value of taking action a in state s equals the immediate reward plus gamma times the value of the best action in the next state. DQN turns that into a regression target: for a remembered transition, y is r plus gamma times the max Q of the next state from a frozen target network, or just r if the episode terminated. The loss is the squared difference between Q(s, a) and y, and only the output for the action taken gets a gradient. Repeating that propagates real rewards backwards through the value estimates.
