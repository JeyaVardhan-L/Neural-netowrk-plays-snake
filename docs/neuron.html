Chapter 04

One neuron

A neuron multiplies, adds and then clips at zero. The clipping looks like a detail; without it, this snake provably cannot learn to play.

Entry 04 · the first line of snake_ai/network.py

Multiply, add, clip

A neuron takes some inputs x1, x2, …, multiplies each by a weight, adds them up, adds a bias, and passes the result through an activation function:

z = w1x1 + w2x2 + w3x3 + b      h = max(0, z)

The weights say how much each input matters and in which direction. A negative weight on "danger ahead" means danger pushes this neuron down. The bias is a threshold: how much evidence the neuron needs before it says anything. max(0, z) is called ReLU, the rectified linear unit. Positive values pass through unchanged, negative values become 0.

Training never changes the inputs or the formula. It only changes the weights and biases. "Learning" means finding numbers for those.

Why the clip matters: a proof with a snake

Take ReLU out and every layer is a matrix multiply plus a constant. Two of those in a row are still one matrix multiply plus a constant: (xA + a)B + b = x(AB) + (aB + b). However many layers you stack, without a nonlinearity the network is a linear model: each input adds a fixed amount to each Q-value, whatever the other inputs are.

Here is a situation this snake meets constantly. The food is up. If the snake is heading right, the correct move is to turn left. If it is heading left, the correct move is to turn right. Same input switched on, opposite answers, depending on another input.

Can a linear model do that? Look at the difference between the left and right Q-values, which is also linear: some number a for "food up", b for "food down", c for "heading right", d for "heading left", plus a constant e. With no danger around and the food straight up or straight down, we need:

  • heading right, food up: prefer left, so c + a + e > 0
  • heading left, food down: prefer left, so d + b + e > 0
  • heading left, food up: prefer right, so d + a + e < 0
  • heading right, food down: prefer right, so c + b + e < 0

Add the first two lines: a + b + c + d + 2e > 0. Add the last two: a + b + c + d + 2e < 0. Both cannot be true. No linear model can steer this snake towards food, whatever its weights. This is the same shape of problem as the famous XOR example: the answer depends on a combination of inputs, not on any one of them.

A hidden layer with ReLU fixes it. One hidden neuron can learn to fire only for "heading right and food up", another only for "heading left and food up", and the output layer gives each its own vote. That is why the network has a hidden layer at all, and why chapter 12 found that 4 hidden neurons are not enough: there are too many combinations to cover.

Why ReLU and not something else

Older networks used the sigmoid, 1 / (1 + e−z), which squashes everything into 0 to 1. Its slope is at most 0.25 and almost 0 for large inputs, so gradients shrink as they pass back through layers. ReLU's slope is exactly 1 when the neuron is on and 0 when it is off. It is cheap, it does not shrink gradients, and its derivative is one line of code: (h > 0). The downside is that a neuron whose z is negative for every input never gets a gradient again: a dead ReLU. With 64 units and only 256 possible inputs, losing a few does not hurt here.

IN:Why does a neural network need a nonlinear activation?
OUT:

Without it, any stack of layers collapses into a single linear function, so depth adds nothing. In my snake, "food up" means turn left when heading right and turn right when heading left. A linear model gives "food up" one fixed weight per action, and I can show the four required inequalities contradict each other. A hidden ReLU layer lets individual neurons respond to combinations like "heading right and food up", which is exactly what the policy needs.
